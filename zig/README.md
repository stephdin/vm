# Zig version

This is a rewrite in Zig with three goals:

1. Learn Zig
2. Design my own simple functional programming language
3. Learn about compilers and vms

This is the plan:

Source Code (.mylang) => Bytecode/Assembly (.myasm) => Run in VM

I need the following steps:

1. Lexer
2. Parser
3. Semantic Analysis
4. Codegen
5. VM

And i need some code samples for the language. The following features are planned for now:

- immutable variables/constants
- functions
- control flow
- loops
- comparison operators (==, <, >) 
- arithmetic (+, -, *, /)
- boolean (true/false, and, or, not)
